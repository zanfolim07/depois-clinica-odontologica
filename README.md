# Sorriso Lumière: site "depois"

Versão reformulada do site da clínica fictícia Sorriso Lumière, feita com React + Vite e sem banco de dados.

```bash
npm install
npm run dev
```

Abre em http://localhost:5302. Todo o conteúdo (contatos, tratamentos, equipe, depoimentos e FAQ) fica em `src/data.js`.

Veja o [README principal](../README.md) para os detalhes do projeto e os créditos das imagens.
